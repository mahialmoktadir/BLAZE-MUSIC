## Overview

**BLAZE MUSIC** is a premium Discord music bot and management platform designed to deliver a powerful, reliable, and customizable music experience.

It combines advanced music playback, 24/7 radio, intelligent queue management, premium subscriptions, and a modern web-based admin dashboard.

---

## Key Features

1. **Advanced Music System**
   - Play, pause, resume, skip, and stop.
   - Music search and queue management.
   - Shuffle, loop, volume, and seek controls.
   - Interactive Discord slash commands.

2. **24/7 Radio System**
   - Continuous music playback.
   - Randomized authorized music library.
   - Automatic track switching.
   - Voice reconnection and recovery.

3. **Music Provider Integration**
   - YouTube metadata and search.
   - Spotify metadata and track identification.
   - SoundCloud where authorized.
   - Direct audio streams and licensed music sources.

4. **Premium Subscription System**
   - Free and Premium membership.
   - Monthly and yearly subscriptions.
   - Custom premium plans.
   - Subscription activation and expiration management.

5. **Bot Appearance Customization**
   - Custom music embeds.
   - Personalized colors and thumbnails.
   - Custom activity and status.
   - Radio and announcement templates.

6. **Advanced Admin Dashboard**
   - Live bot monitoring.
   - Server and voice management.
   - Music and radio controls.
   - Premium and subscriber management.
   - Analytics, logs, and system settings.

7. **Security & Reliability**
   - Discord OAuth2 authentication.
   - Owner-based authorization.
   - Secure API management.
   - Automatic recovery and error monitoring.

## Technology Stack

- **Bot:** Node.js, TypeScript, discord.js
- **Voice:** @discordjs/voice
- **Backend:** Fastify / NestJS
- **Frontend:** Next.js, React, Tailwind CSS
- **Database:** PostgreSQL, Prisma
- **Queue:** Redis, BullMQ
- **Testing:** Vitest
- **Deployment:** Docker & Docker Compose
